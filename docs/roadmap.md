# ESP32 智能环境控制终端 — 作品进化路线

> 从一块 ESP32 到一座会感知的房子

---

## 三段式 IoT 架构

```
交互应用层   Web Dashboard · 21 条 REST API · WebSocket 实时推送
平台服务层   Mosquitto · FastAPI · paho-mqtt · SQLite 6表 · AI引擎
感知控制层   ESP32#1(主控) · ESP32#2(传感器) · 11 类传感器/执行器
```

---

## 进化路线

```
 v0.1         v0.5         v1.0         v1.5         v2.0         v3.0
单板验证  →  双板雏形  →  全屋落地  →  智能联动  →  AI 赋能  →  云端生态
```

| 内容 |

### v0.5 — 双板雏形

```
ESP32 #1 主控板:  DHT11 · 6路灯 · RGB · OLED · 风扇
ESP32 #2 传感器板: 超声波 · 光敏 · PIR · CO2 · 舵机
双板独立主题，走同一 Broker，互不干扰
```

| 内容 |
|---|
| 双 ESP32 GPIO 全分配 |
| 主控板 21 条指令可执行 |
| 传感器板固件框架就绪 |

✅ 里程碑：双板独立运行，消息各走各 topic

---

### v1.0 — 全屋落地

> 数据能存、设备能控、页面能看

```
ESP32 → Mosquitto → FastAPI → SQLite (6表)
                        ├── REST API (21条)
                        ├── WebSocket (实时)
                        └── Dashboard (看板)
```

| 内容 |
|---|
| FastAPI + paho-mqtt + aiosqlite |
| 6 张表：devices · telemetry_log · commands · config · message_log · rfid_log |
| API：/api/device · /api/telemetry · /api/command · /api/ai_report |
| Dashboard：纯 HTML/CSS/JS · 71KB · 零依赖 |
| 21 条 MQTT 指令覆盖全部执行器 |
| 响应时间：鼠标点击 → 500ms 设备动作 |

✅ 里程碑：全栈打通，可演示可答辩

### v1.5 — 智能联动

> 不用人管，自己会反应

| 场景 | 触发条件 | 自动响应 |
|---|---|---|
| 🛌 睡眠 | 湿度 > 85% | 风扇自动除湿 → 降到 82% 关 |
| 🚶 起夜 | PIR 感应到人 | 自动开厕所灯 → 离开关 |
| ☀️ 清晨 | 光敏 > 1700 | 自动关闭夜灯 |
| 🌧 白天 | 光敏 < 1500 | 自动开床后灯补光 |
| 🚪 离家 | Dashboard 一键 | 关闭全部灯光/风扇/RGB |
| 🔒 安全 | PIR + 超声 <20cm | WebSocket 实时告警推送 |
| 🌫 空气 | CO2 > 1500ppm | 自动开风扇排风 |

| 内容 |
|---|
| 服务端 mqtt_client.py 全链路联动 |
| 阈值远程下发 config topic |
| sensor_node.py 框架就绪 · 驱动已集成 |

✅ 里程碑：人到灯亮 · 人走灯灭 · 空气差就换气

### v2.0 — AI 赋能

> 从数据监控到智能理解

```
传感器 → AI 异常检测 → 趋势预测 → 自动告警 → WebSocket 推送 → Dashboard
```

| 能力 | 说明 |
|---|---|
| 异常检测 | 实时分析传感器数据，识别偏离模式 |
| 趋势预测 | 基于历史遥测预测温湿度/CO2 变化 |
| 自动告警 | 超阈值 → 实时推送 + Dashboard 弹窗 |
| 数据聚合 | 每小时 flush → CSV 导出 · /api/ai_report |

✅ 里程碑：系统具备"感知 + 分析 + 决策"能力
