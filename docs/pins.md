ESP32 唇语读 IoT 项目 — 硬件引脚对照表（双板方案）
=====================================================
项目路径: E:\esp32_project
架构: 双 ESP32，通过 MQTT Broker 通信（同网段 WiFi）

  ESP32 #1 主控板  —  执行器（灯、风扇、RGB、OLED、DHT11）  main.py
  ESP32 #2 传感器板 —  传感器（超声波、光敏、红外、舵机、RFID、CO2）  待开发

说明
----
- 下表 GPIO 编号为 ESP32 芯片引脚号，开发板丝印常见为 Dxx。
- 两块板各自独立编号，GPIO 号可相同但物理上是两块不同的芯片。
- 输出引脚默认低电平关闭；继电器、房间灯为高电平触发（relay.value(1) 为开）。
- RGB 灯使用 PWM 调光，占空比范围 0–1023。
- 第二块板程序尚未编写，代码变量名为规划预留。

硬件接线对照（按模块）
----------------------

【1】DHT11 温湿度传感器
  - VCC  → 3.3V
  - GND  → GND
  - DATA → GPIO 27 (D27)

【2】继电器 + 风扇
  - IN   → GPIO 14 (D14)
  - VCC  → 5V（按模块规格）
  - GND  → GND
  - COM/NO → 风扇电源回路
  - 状态 LED1 → GPIO 12 (D12)
  - 状态 LED2 → GPIO 13 (D13)

【3】0.96 寸 OLED（SSD1306，128×64，I2C）
  - SDA  → GPIO 32 (D32)
  - SCL  → GPIO 22 (D22)
  - VCC  → 3.3V
  - GND  → GND

【4】RGB 彩灯（PWM 共阴/共阳按实际模块调整）
  - R    → GPIO 26 (D26)
  - G    → GPIO 25 (D25)
  - B    → GPIO 33 (D33)
  - 公共端 → VCC 或 GND（依模块类型）

【5】房间照明（6 路数字输出）
  - 柜子灯   → GPIO 15 (D15)   指令 8/9
  - 床后灯   → GPIO 2  (D2)    指令 10/11
  - 床下前灯 → GPIO 4  (D4)    指令 12/13
  - 床头灯   → GPIO 18 (D18)   指令 14/15
  - 上左灯   → GPIO 19 (D19)   指令 16/17
  - 厕所灯   → GPIO 5  (D5)    指令 18/19

MQTT 指令与功能对照
-------------------
主题: lip_reading/iot（订阅）

| 指令 | 功能 |
|------|------|
| 1    | 强制开启风扇/继电器 |
| 2    | 强制关闭风扇/继电器（湿度 <85% 后恢复自动） |
| 3    | 强制开启风扇/继电器 |
| 4    | 强制关闭风扇/继电器（湿度 <85% 后恢复自动） |
| 5    | 读取温湿度并发布到 lip_reading/src_text |
| 6    | RGB 暖色 |
| 7    | 关闭 RGB |
| 8–19 | 各房间灯开/关（见上表） |

风扇自动控制（无需 MQTT）
-----------------------
  - 湿度 ≥ 85%：自动开启风扇（GPIO 14 继电器吸合）
  - 湿度 ≤ 82%：自动关闭风扇（滞回防抖动）
  - MQTT 指令优先级高于湿度传感器

模块选型（规划）
----------------
  - 超声波: HC-SR04
  - 光敏: LDR 分压 + ADC（或 LM393 数字模块，仍接 ADC 脚）
  - 红外: 人体 PIR 或避障模块（数字输出）
  - 舵机: SG90（独立 5V 供电，信号接 ESP32）
  - RFID: RC522（SPI）
  - 二氧化碳: SCD41（I2C，推荐；勿用 MH-Z19 UART 以节省引脚）

硬件接线对照（按模块）
----------------------

【1】超声波 HC-SR04
  - VCC  → 5V
  - GND  → GND
  - TRIG → GPIO 17 (D17)
  - ECHO → GPIO 34 (D34)，经分压电阻接 3.3V 逻辑

【2】光敏传感器（LDR 分压）
  - 分压输出 → GPIO 35 (D35)
  - VCC/GND → 3.3V / GND

【3】红外传感器（PIR / 避障）
  - VCC  → 3.3V 或 5V（按模块）
  - GND  → GND
  - DO   → GPIO 36 (D36)

【4】舵机 SG90
  - 信号 → GPIO 16 (D16)
  - VCC  → 5V（独立供电，勿用 ESP32 3.3V 直接带）
  - GND  → GND（与 ESP32 共地）

【5】RFID RC522（SPI）
  - SCK  → GPIO 18 (D18)
  - MOSI → GPIO 23 (D23)
  - MISO → GPIO 19 (D19)
  - CS   → GPIO 21 (D21)
  - RST  → 3.3V（常高，不占引脚）
  - VCC  → 3.3V
  - GND  → GND

【6】二氧化碳 SCD41（I2C）
  - SDA  → GPIO 32 (D32)
  - SCL  → GPIO 22 (D22)
  - VCC  → 3.3V
  - GND  → GND
  - I2C 地址: 0x62（默认）

传感器板已占用 GPIO

GPIO 16, 17, 18, 19, 21, 22, 23, 32, 34, 35, 36

传感器板空闲 GPIO（备用）

  - 勿用: GPIO 1, 3（USB 串口）, GPIO 6–11（Flash）

双板协作说明
------------
  - 两块 ESP32 各自连接同一 WiFi 与 MQTT Broker
  - 主控板负责执行（灯、风扇、RGB、OLED 显示、环境温湿度）
  - 传感器板负责采集（距离、光照、人体/红外、CO2、RFID、舵机动作）
  - 传感器板通过 MQTT 发布数据，主控板或上位机订阅处理
  - 舵机、RFID 等与传感器板本地 GPIO 直连，不经主控板转发
